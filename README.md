# Recipe Classification: Muffin vs Cupcake

Classifying recipes as muffin or cupcake based on ingredient quantities using Machine Learning classifiers.

## Dataset
- 20 recipes with 8 ingredient features (Flour, Milk, Sugar, Butter, Egg, Baking Powder, Vanilla, Salt)

## Project Workflow
1. Data cleaning and basic EDA (recipe distribution, ingredient usage)
2. Encoded target labels and split data into training/testing sets
3. Built and compared Decision Tree, Random Forest, and SVM classifiers
4. Visualized feature importance and SVM decision boundary

## Models Compared
- Decision Tree Classifier
- Random Forest Classifier
- Linear SVM (Support Vector Machine)

## Tools Used
- Python (pandas, numpy, scikit-learn)
- Matplotlib, Seaborn
